# NLBSE 2027 · структура и независимый сигнал для функций без правил

В двух прежних отложенных группах сравнили синтаксические признаки, фрагменты имён вызовов и независимый UniXcoder. Прежнее число ложных срабатываний сохранено **по каждому проекту**. Порог для этой диагностики использует метки проекта. Отдельно сохранены результаты с порогами, выбранными на файлах разработки. Для методов, требующих новый вызов модели, измерена его стоимость на внутренних файлах. Представленные варианты не заменили архив раунда 22 с локальным баллом **0,96211**. ## Синтаксические связи

Из `Function` извлекли количество узлов, операторов и вызовов, глубину и аргументы. В связном варианте учитывается роль вызова в ветке, повторное появление переменной из условия в той же ветке и порядок событий в одном блоке. Базовый вариант сохраняет числа и типы узлов без этих связей. В отдельной абляции разобрали имена вызовов на подслова и учли, где они используются. Функции с неполным разбором остаются в выборке. C++-грамматика отметила ошибку разбора у **35 128 из 214 586** обучающих строк. ## Независимый UniXcoder

Для отложенных проектов использованы сохранённые прогнозы проектной версии UniXcoder, обученной вне файлов развития и проверки. Вариант с оценкой ожидаемой пользы вызова и приблизительным бюджетом 3% длины на разработке исправил **49 и 2** TP при прежних FP. На тестах он запросил 3 669 и 299 функций. Фиксированный порог маршрута переносится между проектами, поэтому фактическое число запросов меняется. [Группа A](adviser/test_a/results.json) · [Группа B](adviser/test_b/results.json)

На официальной внутренней калибровке аналогичная политика для официального чекпойнта вернула **3 TP при 100 FP**. Для неё измерены три прогона выбранных 37 функций. Медиана составила **0,0206 с** учитываемого времени и **1 769 GFLOPs**. После пересчёта дополнительной стоимости на размер публичной выборки прогнозируемое изменение балла **−0,00056**. На отдельной проверочной группе фиксированный порог добавил 5 TP и 9 FP. На официальной калибровке ни одна из 16 политик не окупилась. [Политики, измерения и пороги](adviser/official/policy.json)

## Где остаётся выигрыш

В десяти сохранённых наборах прогнозов нашлось хотя бы одно правильное решение для **232 из 397** нынешних пропусков vulnerability и **611 из 712** ложных срабатываний. Среди функций без точного срабатывания правил это 195 из 345 и 330 из 369 соответственно. Идеальный выбор по известной метке при условно прежней стоимости даёт 0,97442. Это диагностический расчёт покрытия ошибок. Он использует метки публичного набора и не учитывает стоимость вычисления альтернатив. Ветвления и ещё один вызов UniXcoder дали слишком мало пользы, чтобы приблизиться к этому значению. [Покрытие ошибок и хеши](complement.json)

## Воспроизведение

На Banana хранится полный кеш разреженных признаков. Манифесты, конфиги, прогнозы, параметры голов и журналы доступны рядом с отчётом. Команды запускаются из корня экспериментов.

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2
p=.venv/bin/python
r=nlbse/round23
$p "$r/features.py" --workers 5
for part in test_a test_b; do
  $p "$r/scope_eval.py" "$part"
  $p nlbse/cuda_launch.py "$r/latent_expert.py" "$part" fit
  $p nlbse/cuda_launch.py "$r/latent_expert.py" "$part" collect
done
$p "$r/call_roles.py"
$p "$r/adviser.py"
$p nlbse/cuda_launch.py "$r/adviser_official.py"
python3 "$r/complement.py"
python3 "$r/summarize.py"
```
