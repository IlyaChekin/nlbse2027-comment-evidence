# NLBSE 2027 · контрастивные представления CodeT5+ для vulnerability

Проверены 84 223 функции с наблюдаемым отрицательным ответом сканера. CodeT5+ читает ровно те же подстроки, что Qwen и UniXcoder в раунде 46. Для короткого и длинного окна это 23 961 и 76 592 функции, которые окно покрывает полностью. У CodeT5+ собственный токенизатор. Модель получила все его токены в каждой подстроке. Веса и исходная конфигурация закреплены ревизией `d9f3a534af4252f04b10cd9f78e05037542d10f6`, лицензия BSD-3-Clause. Штатный T5-энкодер и слой проекции воспроизвели семь опубликованных координат контрольного вектора с максимальной погрешностью 4,53 × 10⁻⁵. Это профили сбора представлений на RTX 4090. Время токенизации обоих окон 37,60 с. В сравнении использованы 256-мерная проекция, состояние первого токена, сходство с размеченными соседями, смесь с UniXcoder и перенос в компактную модель. Для поиска источники сбалансированы по метке, свои файлы и токенные копии исключены. [Короткое окно](embeddings/96/receipt.json) · [Длинное окно](embeddings/384/receipt.json)

Поиск по длинному окну до проекции после вето сканера вернул **+8/+5 TP** при прежних FP каждого проекта, сверх сильнейших контролей **+5/+1**. На независимых внутренних файлах замороженный порог потерял 1 TP при прежнем FP. Ни один из **990** сценариев с CodeT5+ не прошёл одновременно проектный и внутренний отбор. Сквозного публичного замера нового кандидата не потребовалось. Подтверждённый балл раунда 38 **0,964721**. ## Воспроизведение на Banana

Массивы представлений `embeddings/*/*.npy` и веса `model/pytorch_model.bin` хранятся на Banana. Таблицы, оценки, замороженные головы, построчные прогнозы и контрольные суммы сохранены локально.

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 RAYON_NUM_THREADS=4
py=.venv/bin/python
r=nlbse/round47
$py "$r/embed47.py" pack
for width in 96 384; do
  $py nlbse/cuda_launch.py "$r/embed47.py" "$width"
done
for part in test_a test_b official; do
  $py nlbse/cuda_launch.py "$r/fit47.py" "$part"
done
$py "$r/compare47.py"
$py "$r/audit47.py"
```
