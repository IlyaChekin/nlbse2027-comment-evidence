# NLBSE 2027 · пропуски MAT и дистилляция структурных мотивов

22 ноября 2026 года. По MAT проверены локальные признаки полного текста и найдено исходное происхождение части меток. Из 43 публичных пропусков без комментариев подтверждены 29 тегов в комментарии перед функцией и один тег внутри исходного диапазона. На обычном входе лучший новый признак возвращает один пропуск при 0 FP на второй группе отложенных проектов только с диагностическим порогом. Замороженный порог сохраняет прежнее число пропусков. [Отчёт MAT](mat_residual/README.md) · [Черновик статьи](../paper/round18/main.pdf)

## Можно ли перенести токенные и AST-мотивы в один энкодер

Ранее токенные мотивы улучшали перенос только при непосредственном расчёте отдельной ветви на инференсе. Здесь две разреженные головы оценивают последовательности ролей идентификаторов и связи узлов AST по всей функции. Обе головы обучаются на четырёх из пяти групп и предсказывают пятую группу. Все пять групп покрывают 153 628 функций fit. Токенные и синтаксические логиты объединены с весами 0,60 и 0,40. Сохранены контрольные суммы признаков, разбиения, метки и out-of-fold вероятности. [Учитель и хеши](teacher/fit.json) · [Логи обучения учителя](teacher.log)

Последующая эпоха сохраняет компактную архитектуру, обучающие строки, порядок батчей и инференс. Сравниваются прежний нейронный учитель, структурные цели вместо прежних, смесь логитов, а также замена на тех обучающих примерах, где out-of-fold структурные оценки ближе к известной метке. MAT-цели и правило по комментариям сохраняются. Два seed фиксированы.

| Цель дистилляции | Seed 42, Δ TP при 448 FP | Seed 101, Δ TP при 448 FP |
|---|---:|---:|
| Прежний учитель | −10 | −8 |
| Токенные и AST-мотивы | +7 | −3 |
| Смесь двух учителей | 0 | −2 |
| Замена цели на части примеров | −9 | −9 |

Изменения в таблице относительно исходного энкодера до дополнительной эпохи. Чистая дистилляция мотивов дала +17 и +5 TP относительно парных контролей этой эпохи. Она дала +88 и +53 TP на разработке при одинаковом FP и поэтому выбрана для переноса. На независимом внутреннем сплите официального train получены +2 TP при 22 FP на калибровке и +2 TP / +3 FP в отдельной проверке при замороженном пороге. [Прогнозы двух seed](project_results.csv) · [Внутренняя калибровка](official/policy.json)

На 30 655 публичных функциях в трёх чередующихся прогонах получено 0,957242 против 0,957827 у парного контроля. При 700 FP возвращены три дополнительных TP vulnerability. Замороженный порог дал +109 TP и +164 FP, а средний F1 уменьшился с 0,93196 до 0,93108. Второй вид потребовался 2 694 функциям вместо 2 084. MAT совпал на всех строках. Для подачи выбран проверенный раунд 16. [Измерения и прогнозы](public_results.csv) · [Проверенный архив](../submission/NLBSE2027_round16_tool.zip)

## Сколько сигнала остаётся до дистилляции

Логистическое объединение двух разреженных оценок с базовой нейронной оценкой обучено только на 21 642 функциях Linux из отдельных файлов. При 448 FP оно возвращает +6 TP на отложенной группе, смешивание с 25% структурного логита возвращает +5. По разработке выбран вес 50%. Он возвращает +150 TP при 1 414 FP на разработке и даёт −2 TP при 448 FP на отложенной группе. Прямое объединение показывает разницу между разработкой и переносом на проекты. Этот эксперимент не включает замер прямой структурной ветви на публичном наборе. [Оценки до дистилляции](direct_teacher/results.json)

## Воспроизведение

Веса и исходные parquet хранятся на Banana. Прогнозы, конфигурации порогов, SHA-256 и логи рядом с отчётом. Пересчёт из прогнозов через `report.py` работает без GPU и исходных данных.

```bash
export OMP_NUM_THREADS=3 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2
py=.venv/bin/python
r=nlbse/round18
$py "$r/structural_teacher.py" --workers 3
for seed in 42 101; do
  $py nlbse/cuda_launch.py "$r/structural_distill.py" fit_project --seed "$seed"
  $py nlbse/cuda_launch.py "$r/structural_distill.py" eval_project --seed "$seed"
done
for stage in fit_official tune public; do
  $py nlbse/cuda_launch.py "$r/structural_distill.py" "$stage"
done
$py nlbse/cuda_launch.py "$r/direct_teacher.py"
python3 "$r/report.py"
```
