# NLBSE 2027 · восстановление пропусков MAT

В обычном конкурсном входе единственное диагностическое улучшение дало обучение на функциях с удалёнными разметочными комментариями и на естественных пропусках. Модель вернула **1 из 24** пропусков при **0 FP** на второй группе. Восстановленный пример уже содержал комментарий. С порогом, зафиксированным на разработке, обе группы и публичный набор дали **0** возвращённых случаев. Из пяти обученных вариантов ни один не вернул случай без комментария при исходном FP на отложенных проектах или на публичных данных. [Сверенная таблица](results.csv)

## Что даёт только текст функции

База проверяет четыре тега по границам слова в комментариях полного текста. Новые признаки описывают расположение комментария, ссылку на задачу, похожее на тег первое слово, заглушки и форму ветвлений в коде. Два варианта дополнительно используют синтетическое удаление комментариев у функций с видимыми тегами. Контрольные преобразования исследуют продолжения строк C/C++ и совместимые Unicode-варианты тегов. На исследованных сплитах ни одно из этих двух преобразований не обнаружило новый тег.

Обучение использует 153 628 функций, включая 338 положительных пропусков базы. Калибровка использует 21 797 функций. Группа A — Chromium, QEMU, FFmpeg. Группа B — Firefox, Android, PHP, ImageMagick, radare2, krb5 и file. Обе группы исключены из обучения и калибровки. В диагностическом столбце порог пересчитан на метках оцениваемой группы, чтобы оставить её прежнее число FP. Зафиксированный порог использует только 21 797 функций для калибровки.

| Группа | Функций | Базовые FP | Пропуски | Возвращено при том же FP | Возвращено с зафиксированным порогом |
|---|---:|---:|---:|---:|---:|
| A | 31 098 | 2 | 84 | 0 | 0 |
| B | 7 899 | 0 | 24 | 1 | 0 |
| Публичная | 30 655 | 1 | 62 | 0 | 0 |

На группе B диагностический MAT F1 меняется с 0,93750 до 0,94026. Порог обучения 0,95736, порог при диагностических 0 FP 0,47728. На разработке ни один метод не исправил пропуск при исходном FP. Замороженный выбор сохраняет базу. На публичном наборе 443 TP, 1 FP и 62 FN совпадают с архивом раунда 16. ## Где остались комментарии

В MADE-WIC к функции привязываются внутренние и предшествующие комментарии. В конкурсной постановке предсказатель получает только поле `Function`. Для отдельного исследования происхождения меток мы нашли функции без распознанных комментариев в закреплённых снимках исходников из статьи. Сравнение требует единственной полностью совпавшей последовательности токенов без комментариев и сохраняет строковые литералы. Мы проверяем тег внутри исходного диапазона или в примыкающем предшествующем комментарии с допустимым разрывом до одной пустой строки. [MADE-WIC](https://arxiv.org/html/2408.05163v1#S3.SS1) · [Описание входа NLBSE](https://github.com/nlbse2027/code-comment-classification#dataset)

| Проект | Пропуски без комментария | Однозначно найдено | Тег перед функцией | Тег внутри исходной функции | Отрицательные с таким тегом / найденные отрицательные |
|---|---:|---:|---:|---:|---:|
| Chromium, отложенный | 38 | 18 | 14 | 3 | 4 / 737 |
| Firefox, отложенный | 15 | 12 | 12 | 0 | 0 / 91 |
| Linux, калибровочный | 33 | 27 | 26 | 0 | 0 / 227 |

Итого у отложенных Chromium и Firefox подтверждены **26 тегов перед функцией и ещё 3 внутри исходного диапазона**. Отрицательные контроли из тех же файлов, без комментариев во входе. Файлы для проверки выбраны по наличию пропуска, а часть снимков не удалось скачать или сопоставить, поэтому эти доли относятся к проверенным примерам. Исходники использованы только для аудита. Предсказания в предыдущем разделе получены из `Function`. [Сводка по снимкам](source_results.csv) · [Список совпадений и SHA-256 источников](source_audit.json)

На публичном наборе к этим трём снимкам относились 38 из 43 пропусков без комментариев. Нашлось 31 однозначное совпадение. В 29 случаях тег стоял перед диапазоном, ещё в одном внутри исходного диапазона. В одном совпадении соседнего тега не было. В 55 однозначно совпавших отрицательных контролях тегов в тех же позициях не найдено. [Публичная сверка и хеши](source_audit_public.json)

## Текст для раздела об ограничениях

> The official MAT label can depend on comments outside the supplied function. We matched comment-free false negatives to the token stream of the upstream snapshots cited in MADE-WIC, excluding comments from the matching key. Across the held-out Chromium and Firefox families, 30 out of 53 such inputs had a unique full token match. Of these, 26 had a MAT marker in an adjacent leading comment and three had a marker inside the corresponding source span. On public validation, we traced 30 of the 43 comment-free false negatives to tagged comments absent from the input. These are observed cases in partially matched cohorts. Adding comment layout, code shape, and synthetic comment erasure to a function-only classifier did not recover a comment-free false negative at the reference false-positive count.
