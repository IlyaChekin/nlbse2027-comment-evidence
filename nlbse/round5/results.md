# Выбор дополнительного контекста для CodeT5+

Выбран вариант «128 с пропуском положительных MAT». Воспроизведение исходного инструмента совпало по всем 61,310 бинарным решениям.

За пределами первого окна оказались комментарии у 258 функций. У 64 из них хотя бы один комментарий пересёк границу окна. Старое правило прочитало пропущенные фрагменты и вернуло 19 верных MAT-решений при 0 дополнительных ложных срабатываниях.

Пропуск уже положительных MAT сократил число вторых проходов с 258 до 238. Изменения бинарных решений по двум меткам: [0, 0].

На тех же строках и при той же длине повторное чтение уже виденного фрагмента дало 0,9167 F1, а чтение хвоста дало 0,9264. Удлинение первой части до 768 для длинных функций дало 0,9290 F1.

Медиана трёх прогретых прогонов используется для основных вариантов. Диагностические контроли прошли один раз. GFLOPs рассчитаны по формам плотных операций; время на RTX 4090 и оценки по формуле относятся к публичному сплиту.

Варианты сравнивались на 18 444 строках внутреннего holdout из официального train. Выбор заморожен перед публичным прогоном. Все первичные сравнения сохраняют одни пороги. Метрики, маршрутизация, полный тайминг, интервалы и срезы лежат в [analysis.json](analysis.json).
