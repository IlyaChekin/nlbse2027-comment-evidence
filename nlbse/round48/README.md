# NLBSE 2027 · следы отсутствующего комментария MAT

Новый признак описывает границы сохранённых фрагментов. Он учитывает пустые строки и отступы перед объявлением, положение комментариев в сигнатуре и у входа в тело. Отдельный признак ищет признаки заглушки, включая пустое тело, одиночный возврат константы и коды «не реализовано». Оба вычисляются из `Function`. Ранжировщик обучен на 230 пропусках с подтверждённым тегом перед функцией и 1 215 отрицательных контролях из тех же файлов, всего 1 332 пары. Деревья на всех естественных пропусках и прежняя оценка языка и кода служат контролями. [Признаки, модель и пороги](shape/policy.json)

| Протокол | A · 77 пропусков | B · 23 пропуска |
|---|---:|---:|
| Попарная оценка расположения, прежние 0 FP каждого проекта | 0 | 1 |
| Попарная общая оценка расположения и заглушки, прежние 0 FP каждого проекта | 0 | 1 |
| Оценка заглушки отдельно, прежние 0 FP каждого проекта | 0 | 0 |
| Замороженный общий порог, попарная оценка расположения | 0 TP, 0 FP | 0 TP, 0 FP |

Обе попарные оценки подняли один и тот же пример Android с видимым комментарием выше всех отрицательных строк проекта. Для этого потребовался диагностический порог по меткам Android. На development из 21 797 строк при 0 FP не вернулось ни одного пропуска. Дополнительная диагностика с отдельными порогами по наличию комментария и длине до 200 символов также дала 0 возвратов с замороженными порогами. Порог, выбранный по development, сохранил исходный разбор MAT. [Таблица](shape/comparison.csv) · [Раздельные пороги](strata/comparison.csv) · [Построчная сверка](audit.json)

Из 100 пропусков на A/B **75 вообще не содержат лексического комментария**. На A таких 54, на B 21. Точное сопоставление с уже закреплёнными снимками подтвердило пропавший тег у **31** функции, из них 19 на A и 12 на B. Из них 29 без комментария и две с другим видимым комментарием. Этот аудит охватывает ранее выбранные исходники. Доля подтверждённых случаев зависит от доступности снимков и точного совпадения, поэтому её нельзя переносить на все пропуски. [Аудит источников и хеши](audit.json)

## Сверка с двумя версиями исходной разметки

Связали строки по проекту, пути и точной последовательности токенов после удаления комментариев и пробелов. Строковые литералы сохранены. Взяли все функции из файлов, где был хотя бы один пропуск. Выявленные теги находятся в отдельном исходном поле `LeadingComment`. Диагностика использует этот дополнительный контекст. Конкурсный предсказатель получает `Function`. [Спецификация входа](https://github.com/nlbse2027/code-comment-classification#dataset) · [MADE-WIC v2](https://zenodo.org/records/13370805) · [MADE-WIC v3](https://zenodo.org/records/15126132)

| Проверка дополнительного контекста | A · 77 пропусков | B · 23 пропуска | Публичный · 61 пропуск |
|---|---:|---:|---:|
| MADE-WIC v2, TP / FP | 77 / 0 | 22 / 0 | 57 / 0 |
| MADE-WIC v3, TP / FP | 77 / 0 | 22 / 0 | 58 / 0 |
| Сопоставленные отрицательные строки | 1 617 | 202 | 185 |

На публичном наборе у одной сопоставленной функции тег появился в исправленной версии. В обеих проектных группах результаты двух исходных архивов совпали. Совместно с прежней сверкой закреплённых исходников подтвердили отсутствующий тег у **59 из 61** публичного пропуска, из них **18** подтверждены впервые. У двух остававшихся пропусков совпадение стало точным и уникальным после стандартного удаления C-переносов строк с обратной косой чертой. В обеих записях v3 метка MAT равна 1 и тег находится в `LeadingComment`. Всего установлено происхождение **61 из 61** публичного пропуска. Сравнение двух версий проверено по контрольным суммам Zenodo и хешам всех архивов. Сохранены построчные соответствия и хеши найденных комментариев. [Сравнение](madewic/comparison.csv) · [Построчная сверка](madewic/results.json) · [Сверка двух переносов](madewic/unmatched.json)

Подтверждённый локальный балл **0,964721**. При прежней vulnerability и стоимости 16 дополнительных MAT без новых FP дают расчётные **0,970015**. У всех 61 исходный тег находится перед функцией вне конкурсного `Function`. Расчёт с исходным `LeadingComment` составляет **0,983111** при фиксированной стоимости модели и без учёта стоимости добавочного контекста. Публичные данные использовались только для установления происхождения ошибок и пересчёта формулы. ## Воспроизведение на Banana

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2
py=.venv/bin/python
r=nlbse/round48
$py "$r/shape48.py"
$py "$r/audit48.py"
$py "$r/strata48.py"
python3 "$r/fetch_madewic48.py"
$py "$r/madewic48.py"
$py "$r/unmatched48.py"
python3 nlbse/round38/release_summary.py
```

Два исходных архива закреплены контрольными суммами и хранятся на Banana в `round48/madewic`. Локально сохранены результаты сверки, прогнозы, пороги и журналы.
