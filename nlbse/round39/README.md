## Проверка на файлах вне обучения

Прежний линейный остаток обучался заново для каждого из четырёх сгибов с исключением самого сгиба и известных дубликатов. Для сравнения использованы исходные признаки, координаты, форма строки и окрестности, а также разреженные словные признаки для окна рядом с отметкой или окна из середины функции. У окон одинаковое число строк и одинаковое ограничение по символам. Строковые литералы и комментарии убираются. На A, B и внутренней ротации осталось **5 773**, **4 632** и **3 829** пар из одного файла с валидной координатой для обеих сторон.

| Ранг внутри пары | A | B | Внутренняя ротация |
|---|---:|---:|---:|
| Исходная внефайловая оценка | 86,80% | 87,07% | 85,52% |
| С добавкой признака рядом со срабатыванием | 87,71% | 88,52% | 86,49% |
| С добавкой признака из середины функции | 86,85% | 86,78% | 85,49% |

Отобрано 10 из 540 сопоставимых настроек. У двух проверенных вариантов при прежнем FP диагностическое число TP на A снижалось, на B выросло на шесть. Выбранная геометрия прошла за счёт равного TP при сопоставлении с контролем, −2 FP на калибровке и −3 FP с потерей 1 TP на review. Сильные положительные решения проверялись отдельно.   $py "$path/study39.py" "$part"
```bash
  $py "$path/negative39.py" "$part"

for arm in chosen best_local; do
  $py nlbse/cuda_launch.py "$path/live39.py" "$arm"
done
$py "$path/audit39.py"
$py "$path/portfolio39.py"
```
