## Источники и контроль

Объединены подписанные оценки компактного энкодера, прежние разреженные оценки для разных исходов правил и обе ветви маршрутизации. Для предсказания доступен только фактически наблюдавшийся ответ сканера. Контрфактический ответ используется для обучения и проверки ценности вызова, отдельно от признаков селектора.

Новый разреженный источник сочетает лексические признаки, части идентификаторов и триграммы формы токенов. Веса отношений частот классов оцениваются внутри обучающего сгиба, затем складываются с весами линейной головы для инференса. Для внефайловых предсказаний исключались тот же файл и его известные токенные копии. Из финальной разреженной головы дополнительно исключались токенные копии функций из проверочных групп. При сборке признаков на development и отложенных проектах бинарный контроль раунда 38 совпал с архивом. Для внефайловых оценок положительная поправка раунда 38 переобучалась по сгибам, отрицательная ветвь опиралась на более ранний подписанный отступ раунда 32. [Новый источник A](sparse/test_a/receipt.json) · [B](sparse/test_b/receipt.json) · [Внутренняя ротация](sparse/official/receipt.json)

В контрольном стеке изменение решения возможно во всей заданной полосе. Селектор ограничивает поправку функциями с расходящимися знаками. Для второго контроля глобальная голова применяется к тем же расхождениям без отдельного обучения на них. Из **1 719** конфигураций **8** прошли отбор. Ни один из полнообластных стеков не прошёл одновременно обе группы и внутреннюю проверку. На внутренней внефайловой ротации набор компактных оценок выявил 6 995 расхождений, с новой разреженной оценкой — 15 068. У нового источника при этом в область расхождений попали 333 пропуска и 1 384 ложных срабатывания вместо 311 и 1 053. ## Перераспределение сканирования

Проверили, полезно ли расхождение с разреженной оценкой для выбора функций на сканирование. Сохранялось число вызовов и не увеличивалась суммарная длина просканированного текста. Для сохранённых запросов повторено решение раунда 38. Для добавленных использованы архивные контрфактические оценки раунда 32. Ни одна из **216** настроек с разреженными признаками не прошла проверку обеих проектных групп и внутреннего качества. У лучшей по внутреннему критерию настройки с новым источником разность относительно маршрутизатора только по старым оценкам составляет **+14 и −17 TP** при равном FP. ## Воспроизведение

Из корня исследования на Banana. Кеш разреженных признаков сохранён там вместе с закреплёнными parquet. Публичные каталоги текущего замера стоит сохранять перед повторным профилированием.

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 NLBSE_SCANNER_WORKERS=6
export NLBSE_NODE="$PWD/nlbse/round19/weak_satd/runtime/node"
py=.venv/bin/python
path=nlbse/round40
$py "$path/sparse40.py" collect
for part in test_a test_b official; do
  $py "$path/sparse40.py" "$part"
  $py "$path/stack40.py" "$part"
  $py "$path/matrix40.py" "$part"
  $py "$path/route40.py" "$part"
done
$py "$path/select40.py"
$py "$path/select_route40.py"
for arm in chosen combined; do
  $py nlbse/cuda_launch.py "$path/live40.py" "$arm"
done
$py "$path/audit40.py"
```
