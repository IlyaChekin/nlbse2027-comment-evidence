# NLBSE 2027 · парная дистилляция на функциях из одного файла

Проверили перенос порядка оценок GraphCodeBERT и UniXcoder в существующий компактный энкодер. Публичная валидация не участвовала в отборе. На вход каждой головы подавались первые состояния компактного энкодера и уже вычисленные оценки. Две разреженные модели использовались для одного из вариантов отбора строк. На каждой отложенной группе фиксировали прежнее число FP каждого проекта и отдельно проверяли порог из development. Сверенный контроль соответствует раунду 38.

## Отбор функций и результаты

Сначала взяли подписанные пары раунда 37 из одного файла с общим исходом сканера. Оставили пары, где оба учителя ставили положительный пример выше отрицательного, а текущая оценка давала обратный порядок или ничью. После удаления токенных копий оценочных строк осталось **174**, **368** и **321** пара в A, B и внутренней ротации. Сравнили восемь голов, включая контроль без учителей, обычную дистилляцию, правильные порядки по золотым меткам, мягкий порядок учителей и перенос разности их оценок. Во второй итерации для каждой положительной функции подбирали до четырёх отрицательных из того же файла и той же ветви сканирования, близких по длине и текущему отступу. Широкий пул содержит **3 577**, **7 266** и **8 133** пары. Из него **1 696**, **3 233** и **3 677** удовлетворили условию согласия учителей с золотым порядком. Линейная поправка учитывает разность оценок учителей и штраф за изменение текущей оценки на остальных функциях. Простое обучение на золотом порядке на тех же широких парах не улучшило пороговый контроль одновременно на обеих группах. [Широкие пары и пороги](wide/selection.json) · [Веса и состав официальной ротации](wide/official/fit.json)

Ни одна из **1 656** конфигураций первой серии и **612** второй не прошла одновременно контроль на A/B, калибровке и review. Публичный замер отклонённых конфигураций не запускался. Подтверждённый балл **0,964721**, разрыв до 0,97 составляет **0,005279**. ## Воспроизведение

Запуск из корня экспериментов на Banana. Готовые массивы раундов 37, 40 и 41 используются по подписанным манифестам. В каждой ротации сохранены параметры, списки пар по строкам и сгибам, значения порогов, упорядоченные прогнозы и журналы.

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2
py=.venv/bin/python
r=nlbse/round42
for part in test_a test_b official; do
  $py nlbse/cuda_launch.py "$r/fit42.py" "$part"
  $py nlbse/cuda_launch.py "$r/wide42.py" "$part"
done
$py "$r/evaluate42.py"
$py "$r/wide42.py" compare
$py "$r/audit42.py"
```
