# NLBSE 2027 · чувствительность W к переносу строк

Сопоставили конкурсный `Function` и исходный текст MADE-WIC v3 на **34 738 из 37 471** выбранных строк официального train. Сохранили уникальные совпадения по проекту, файлу и последовательности кодовых токенов. Для каждого обучения исключили файлы и точные копии из всей проверочной части. Парные исходники калибровки и review использовались только в диагностических замерах. Убрали неоднозначные лексические совпадения и функции с директивами либо продолжениями строки. Во всех вариантах правка касается пробельного промежутка. После неё проверяется побайтное совпадение последовательностей кодовых и комментарных токенов с конкурсным текстом. [Пары](causal/pairs.json) · [Диагностика](causal/oracle.csv)

## Что именно меняет ответ сканера

| Архивное вмешательство | A, исправлено / испорчено | B, исправлено / испорчено | Внутренний review |
|---|---:|---:|---:|
| Исходные пробелы внутри строк | 0 / 0 | 0 / 0 | 0 / 0 |
| Исходный отступ на прежних границах строк | 140 / 76 | 69 / 25 | 35 / 23 |
| Изменить перенос, сохраняя местный конкурсный отступ | 268 / 7 | 109 / 10 | 39 / 6 |
| Исходный промежуток только на изменившихся границах строк | **270 / 2** | **112 / 5** | **40 / 0** |
| Все совместимые пробельные промежутки | 400 / 25 | 172 / 10 | 74 / 15 |
| Полный архивный текст | 434 / 0 | 187 / 0 | 77 / 0 |

A и B содержат соответственно 14 250 и 2 193 выровненных функций. В них на конкурсном тексте **436** и **188** расхождений с `W`. Условие вмешательства в четвёртой строке требует разной позиции переноса в двух текстах. Затем копируется точный пробельный промежуток, включая отступ. Полный архивный текст может содержать отличные комментарии. В остальных строках таблицы исходные кодовые и комментарные токены сохранены. [Абляция отступов и пробелов](spaces/comparison.csv)

Проверили эти изменения в полном конвейере на внутренних данных. Подстановка реальных ответов сканера после точного восстановления только перенесённых границ дала **+10 TP / −13 FP** по `vulnerability` на калибровке и **+15 TP / −19 FP** на review. F1 review вырос с **0,956997 до 0,969343**. Среди 200 строк review из новых для исходного fit файлов вернулся **1 TP при прежних FP**. Все решения MAT и число запросов сканера остались прежними. Это диагностический результат с архивными данными. [Сквозной пересчёт](endpoint/comparison.csv) · [Прогнозы](endpoint/predictions.npz)

## Предсказание правки из конкурсного Function

На обучающих файлах измерили **91 443** варианта изменения одиночного промежутка. У **4 429** вариантов смена ответа исправляет архивную `W`, у **587** портит верный ответ. Проба стратифицирована по расхождению и используется для обучения. Сравнили оценку исходного переноса, оценку эффекта правки, их произведение и отдельную модель относительного отступа. Применяли до вызова сканера до 1, 3 или 12 правок с порогами из соответствующей калибровки. Сохранились сравнения с пятью фиксированными стилями на общей выборке. [Одиночные пробы](edit/design.json) · [Таблица отбора](comparison/comparison.csv)

Из **24** политик ни одна не прошла проверки на отложенных проектах и review. Вариант с одним переносом по оценке исходного переноса вернул один TP W на B при прежнем FP. Аналогичный порог на A дал одно новое FP. Сочетание прогнозов исходного переноса и эффекта дало +4 TP W при прежнем FP на внутреннем review и −4 TP / +20 FP на A. Заведомо известное исходное форматирование даёт высокий диагностический прирост, а перенос автоматической правки на новые проекты остаётся ограничением. [Замороженные политики](comparison/selection.json) · [Независимый пересчёт](audit.json)

Для следующего опыта сканер с координатами перенёс с архивного текста на конкурсные токены первый найденный участок для **980**, **998** и **554** ранее не найденных W-положительных функций в обучающих частях трёх ротаций. Для каждой ротации сохранена отдельная маска fit. Подтверждённый локальный конкурсный балл остаётся **0,964721**.
