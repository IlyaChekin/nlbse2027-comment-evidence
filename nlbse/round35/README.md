# NLBSE 2027 · попарное обучение и отрицательные ответы сканера

Сравнили обычное дообучение UniXcoder и то же обучение с добавкой попарной потери на функциях из одного файла. Для обеих процедур использованы одинаковые примеры, батчи, исходные веса и две эпохи. Исходный учитель обучен на других файлах соответствующей ротации. Сравнили длинный префикс и короткий фрагмент начала тела вместе с объявлением. Прибавка от попарной потери для префикса составила 0,08, 0,18 и 0,26 п.п. Интервалы bootstrap по файлам во всех трёх ротациях включают ноль. В проверке TP при прежнем FP на обеих группах выбран исходный учитель, **+6 и +5 TP**. Сверх сравнимого изменения порога он даёт **+4 и +3 TP**. Инференс 69 его окон на 4 292 калибровочных функциях занял 0,02975 с оцениваемого модельного времени и 2 438 аналитических GFLOP. Проекция штрафа на публичный размер **0,001203**, прибавка от качества **0,000564**. ## Публичные прогоны на RTX 4090

Все варианты и пороги зафиксированы на project A/B с поправкой на пороговый контроль, development и review. Сравнения выполнены в отдельных сериях по пять пар с чередованием порядка. В каждом прогоне использованы те же 30 655 функций, те же 7 279 запросов к сканеру и 1 990 вторых модельных проходов. Дельты TP и FP ниже относятся к vulnerability. Все решения MAT совпали.

| Вариант | TP A/B при прежнем FP | TP/FP с замороженным порогом на публичном наборе | TP при прежнем публичном FP | Балл / парный контроль | Побед |
|---|---:|---:|---:|---:|---:|
| Линейная проекция объединённого состояния | +4 / +2 | −1 / 0 | −1 | 0,964483 / 0,964526 | 2 из 5 |
| Разреженный символьный признак | +3 / +2 | +3 / +5 | −1 | 0,964446 / 0,964459 | 3 из 5 |
| Расширенная поправка по режимам | +4 / +3 | +36 / +55 | −17 | 0,964234 / 0,964506 | 0 из 5 |

Для расширенной поправки проверены 285 конфигураций. Выбранная обучалась на всех наблюдаемых отрицательных ответах сканера в соответствующей ротации. Она использует четыре случая по знаку оценки до и после запроса, а применяется в пределах 0,75 от порога раунда 34. На публичном наборе изменяемая область включала 396 функций. Для всех **4 476** функций с наблюдаемым отрицательным ответом диагностический потолок **0,971309**. Эти сценарии подставляют истинные метки и локализуют резерв для будущего классификатора. ## Воспроизведение

На Banana закреплены parquet, веса четырёх групп файлов каждой ротации и сохранённые публичные прогнозы. Логи обучения лежат в `train_*.log`, веса и контрольные суммы в `teachers/`. Из корня исследования:

```bash
export OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 NLBSE_SCANNER_WORKERS=6
export NLBSE_NODE="$PWD/nlbse/round19/weak_satd/runtime/node"
py=.venv/bin/python
path=nlbse/round35
for part in test_a test_b official; do
  $py nlbse/cuda_launch.py "$path/teacher35.py" "$part"
  $py "$path/eval35.py" "$part"
  $py "$path/sparse35.py" "$part"
  $py nlbse/cuda_launch.py "$path/project35.py" "$part"
  $py "$path/broad35.py" "$part"
done
$py "$path/select35.py"
$py "$path/select_broad35.py"
$py nlbse/cuda_launch.py "$path/teacher_cost35.py"
$py nlbse/cuda_launch.py "$path/live35.py"
$py nlbse/cuda_launch.py "$path/live35.py" --sparse
$py nlbse/cuda_launch.py "$path/live35.py" --broad
$py "$path/scope35.py"
$py "$path/audit35.py"
```

`source_snapshots/` хранит исходные версии двух профилей и раннего пересчёта; опубликованные журналы подписаны именно ими. Для повторного профилирования текущим исходником сохраните результат в отдельной копии каталога: реальные значения времени изменятся.
